005

side by side

The same request, two answers.

Ask any assistant to write a debounce function. Here's the difference in what actually lands in your editor.

typical assistant
−Sure! Here's a debounce function, step by step:
−function debounce(fn, wait) { ... }
−I've added comments to explain each part.
−Let me know if you'd like it explained further!
keyless
+function debounce(fn, wait) {
+  let t;
+  return (...args) => {
+    clearTimeout(t);
+    t = setTimeout(() => fn(...args), wait);
+  };
+}
